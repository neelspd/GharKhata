# Code of Conduct

## Our Pledge

We want GharKhata to be a welcoming and respectful project for everyone.

Contributors, users, and maintainers are expected to participate in a way that is respectful, constructive, and considerate.

---

## Expected Behavior

Examples of positive behavior include:

- Being respectful of different viewpoints and experiences
- Giving constructive feedback
- Accepting feedback gracefully
- Staying focused on the project and its goals
- Helping others learn
- Assuming good intent where reasonable

---

## Unacceptable Behavior

Examples of unacceptable behavior include:

- Harassment, intimidation, or personal attacks
- Discriminatory language or behavior
- Trolling or insulting comments
- Publishing private information without permission
- Repeatedly disrupting discussions
- Any conduct that would be inappropriate in a professional or collaborative environment

---

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, pull requests, or other contributions that do not align with this Code of Conduct.

Maintainers may also temporarily or permanently ban contributors for behavior that is harmful to the project or community.

---

## Reporting

If you experience or witness unacceptable behavior, please contact the project maintainer.

For now, this project is maintained by Neel Shah.

---

## Scope

This Code of Conduct applies to:

- Repository discussions
- Issues
- Pull requests
- Project documentation
- Any official project communication spaces
